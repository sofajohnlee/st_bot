# 등기 AI 안내봇

등기정보광장 공개 HTML 페이지를 서버에서 조회하고, 질문의 한국어 키워드와 일치하는 내용을 출처 링크와 함께 안내합니다. Cloudflare Workers AI의 공개 가중치 모델 Meta Llama 3.3 70B (`@cf/meta/llama-3.3-70b-instruct-fp8-fast`)가 질문을 검색어로 정리하고 공식 원문 발췌를 근거로 한국어 답변을 생성합니다. 별도의 외부 LLM API 키는 필요하지 않으며 `AI` 바인딩을 사용합니다. 통계 질문은 공식 화면의 공개 JSON 조회 요청으로 처리하며, 수치 합계와 증감은 서버에서 계산합니다.

AI 모델 실행 실패 또는 바인딩 미설정 시 원문 검색 결과로 전환하며, 화면에 AI 답변 사용 여부를 표시합니다. 답변 아래에는 번호가 있는 출처 링크만 표시하며 원문 발췌를 별도 채팅 메시지로 출력하지 않습니다. 검색 자료가 없으면 모델 답변을 생성하지 않습니다. 웹페이지는 비신뢰 데이터로 취급하며 출처 번호를 포함하도록 모델에 지시합니다. 생성 답변의 정확성을 보장하는 것은 아니므로 원문 확인이 필요합니다.

## AI 배포 설정

- `wrangler.jsonc`의 Worker 이름은 실제 서비스 주소에 맞춰 `st-bot`입니다.
- `ai: { "binding": "AI" }`를 배포하면 Workers AI가 연결됩니다. Cloudflare 계정에 Workers AI 이용 권한이 필요합니다.
- Workers AI의 무료 할당량 초과 시 계정 요금제에 따라 비용이 발생하거나 요청이 제한될 수 있습니다. https://developers.cloudflare.com/workers-ai/platform/pricing/
- 질문과 공식 발췌는 Cloudflare Workers AI로 전송됩니다. 개인정보나 비공개 자료를 입력하지 마세요.
- 기존 GitHub Actions의 Cloudflare 배포 자격증명으로 main 변경 시 자동 배포합니다. 토큰 권한에 따라 AI 바인딩 배포가 제한되면 Cloudflare에서 권한을 확인하세요.

## 실행 및 배포

1. Node.js 22 이상에서 `npm test`로 검증합니다.
2. `npx wrangler dev`로 로컬 실행합니다.
3. `npx wrangler login` 후 `npm run deploy`를 실행합니다.
4. 출력된 `https://st-bot.<계정>.workers.dev` 주소를 엽니다. 화면과 `/api/ask`가 함께 배포되므로 서버 주소를 별도로 입력할 필요가 없습니다.

GitHub Actions 자동 배포를 쓰려면 저장소 Settings → Secrets and variables → Actions에 `CLOUDFLARE_API_TOKEN`(Workers 배포 권한), `CLOUDFLARE_ACCOUNT_ID`를 등록합니다. main에 반영하면 기존 배포 워크플로가 실행됩니다. 토큰을 파일에 넣지 마세요.

GitHub Pages를 별도로 쓰면 index.html의 `window.REGISTRY_BOT_API_BASE`에 배포된 Worker URL을 설정하고 같은 변경을 public/index.html에도 반영합니다. 화면 배포용 public 폴더와 루트의 화면 파일은 동일하게 유지합니다.

## 검색 범위와 한계

- 홈페이지, 공지사항, 자료실, 등기현황에서 시작하여 질문과 관련된 직접 링크를 최대 4개 추가 조회합니다. 전체 사이트 검색 인덱스는 아닙니다.
- EUC-KR 문자 인코딩을 처리하며, 조회 타임아웃과 15분 캐시를 적용합니다.
- JavaScript로만 제공되는 게시글·통계 및 PDF 첨부파일 본문은 검색하지 못할 수 있습니다. 로그인, 신청, 파일 다운로드는 수행하지 않습니다.
- 통계는 공식 데이터시각화 화면의 읽기 전용 요청(`/cr/dv/getLastMonth.do`, `/cr/dv/selectRgsCrDvGraph1.do`)을 사용합니다. 인증키 기반 Open API와는 다르며 공식 응답 형식 변경 시 연계 보완이 필요합니다.
- 전국 신청 건수와 지역별 신청 부동산 수를 구분합니다. 지역별 부동산 수는 신청사건 건수나 기간 내 고유 부동산 수가 아닙니다.
- 최신 제공월은 공식 적재정보로 확인합니다. 미공표 기간, 누락된 월, 잘못된 수치는 0으로 대체하지 않습니다. 월·분기·상반기/하반기·연도·최근 N개월(최대 36개월), 기간 합계, 전월·전년동월 대비, 지정 지역 간 비교 및 시도별 순위를 지원합니다.
- 시·도/시·군·구는 공식 지도 XML의 계층 코드를 사용합니다. 중복 지역명은 상위 지역 확인이 필요합니다. 읍·면·동, 세부 주택용도 및 증여/상속 등 상세 원인은 현재 지원하지 않습니다. 지역 코드 및 통계 응답은 15분 캐시됩니다.
- 지역별 경매·공매는 소유권이전 신청 부동산 수입니다. 경매개시결정·공매공고 신청 건수와 혼동하지 않도록 모호한 질의에는 조건을 다시 안내합니다.
- 신청사건 건수를 명시한 지역 질의는 부동산 수로 자동 치환하지 않습니다. 지역별 근저당권은 설정 또는 말소를 지정해야 합니다.
- 조회 시각은 자료의 통계 기준일이 아닙니다. 원문 발췌에는 메뉴 등 주변 텍스트가 포함될 수 있습니다.
- 외부 연결 실패 시 조회 성공처럼 표시하지 않습니다. 사이트의 접근 정책·이용약관을 확인한 후 운영하고, 공개 운영 규모에 맞춰 Cloudflare에서 요청 제한을 설정하세요.

## 구성

worker.js: LLM 답변 및 JSON API. statistics.js: 공식 통계 조건 해석·조회·수치 검증 및 집계. public/: Worker가 제공하는 채팅 화면. 루트 app.js/index.html: GitHub Pages용 화면. 테스트는 실제 사이트에 의존하지 않는 fixture를 사용합니다.

## 통계 질의 예시

- `2026년 9월 전국 경매·공매등기 신청 건수`
- `서울 2026년 1~9월 매매 신청 부동산 수`
- `서울 강남구 2026년 9월 근저당권설정 신청 부동산 수`
- `서울과 부산의 2026년 9월 소유권이전 신청 부동산 수 비교`
- `2026년 9월 시도별 매매 신청 부동산 수 상위 5개`
- `서울 2026년 9월 경매·공매 소유권이전 부동산 수 전월 대비`

일반 안내는 Llama로 생성하고, 통계는 검증된 수치와 조건을 정형 답변으로 제공합니다. 모델이 수치를 변경하거나 임의 계산하지 않습니다.

## PDF 첨부 질문

질문창 위의 PDF 첨부 버튼으로 1개 문서를 선택합니다(20MB, 300쪽, 추출 텍스트 60만 자 이내). 첨부 상태에서 질문하면 공식 웹검색 대신 문서의 관련 발췌를 근거로 답변하며 PDF 페이지 번호를 표시합니다. 이어서 질문할 수 있고 첨부 해제를 누르면 공식 자료 검색으로 돌아갑니다. 요약은 관련 발췌 범위이며 전체 문서의 완전한 검토를 보장하지 않습니다.

PDF.js로 브라우저에서 텍스트를 추출합니다. 원본 PDF는 서버에 저장하지 않으며 추출 텍스트를 Worker 및 Cloudflare AI에 전송합니다. 개인정보나 비공개 문서는 첨부하지 마세요. 텍스트 없는 스캔 PDF와 암호화 PDF는 OCR 처리 또는 암호 해제 후 이용하세요. 페이지 순서는 PDF 파일 기준입니다.

`npm ci` 후 `npm run build`로 PDF.js와 한국어 CMap, 표준 폰트를 배포 자산에 복사합니다. Worker에서는 자체 호스팅 파일을 사용하며 GitHub Pages 화면에서는 버전 고정 CDN을 사용합니다.


## 멀티턴 대화

최근 완료된 6회 질문·답변(총 18,000자 이내)을 브라우저 메모리에 보관하여 서버에 함께 전달합니다. 후속 질문을 독립 질문으로 해석한 후 공식 자료·통계·PDF를 다시 조회하며 이전 답변을 사실 근거로 사용하지 않습니다. 예: `서울 2026년 9월 매매 신청 부동산 수는?` → `그럼 부산은?`. PDF 질의도 이전 문맥을 참조합니다. 새 대화, 페이지 새로고침, PDF 변경·해제 시 이력이 초기화됩니다. 오류 및 조건 확인 답변은 이력에 추가하지 않습니다. 대화와 첨부 텍스트는 답변 처리를 위해 Cloudflare Workers AI로 전송됩니다.

## 통합 등기 안내

기존 통계·등기정보광장 검색·PDF·멀티턴을 유지하고 인터넷등기소 이용, 등기절차, 관련 규정 안내를 추가했습니다. guidance.js의 공식 출처 카탈로그에서 질문별 페이지를 선정하고 관련 본문·조문을 조회합니다. 인터넷등기소, 법제처 생활법령정보, 국가법령정보센터만 근거로 사용합니다. 법령 메뉴·빈 프레임은 법령 근거로 사용하지 않습니다. 법령명 URL은 공식 프레임을 따라 본문을 시도하며 확인 가능한 개별 조문도 검색합니다. 개별 조문 URL의 시행일이 최신을 보장하지 않으므로 답변은 확인된 버전만 설명합니다. 예규·선례 전체 검색 인덱스와 인증 API는 연결되어 있지 않아 본문을 확인하지 못하면 공식 확인 경로를 안내합니다. 공식 사이트 연결 실패·동적 화면은 출처 링크로 안내하며 해당 기능을 이용한 것으로 표시하지 않습니다. 사용자 대신 로그인·결제·열람·등기신청을 실행하지 않습니다.

인터넷등기소 연결 실패 시 2026.10.14. 공식 홈페이지에서 확인한 메뉴 안내를 참고자료로 사용하며 출처에 확인일을 표시합니다. 이 참고자료는 금액·운영시간·상세요건의 근거로 사용하지 않습니다.

## 인터넷등기소 등기절차 안내봇 질문·답변 연계

`iros-chat.js`는 https://www.iros.go.kr/chat/ 와 해당 페이지가 직접 참조하는 동일 경로의 공개 HTML/JSON/JavaScript 자산을 읽어 질문·답변 쌍을 추출합니다. 수집은 최대 7개 자산, 3회 탐색으로 제한하며 원격 JavaScript를 실행하지 않습니다. 공개 질문·답변이 확보되면 한국어 검색어로 관련 항목을 최대 3개 선정해 기존 공식 자료보다 앞에 LLM 근거로 제공합니다. 안내봇 출처와 참고 건수를 화면에 표시합니다. 공개 프런트엔드에서 확인한 `/chat/dialogue`의 일반 안내 조회 요청도 사용합니다. 실제 사용자 질문·대화 이력·PDF는 외부 안내봇에 전달하지 않으며, 고정된 일반 질문과 안내봇이 제시하는 질의 버튼만 조회합니다. 조회용 세션은 독립적으로 생성하며 서버의 공인 접속 식별값은 공개 `/chat/getIp` 응답으로 얻습니다. 로그인·관리자 API를 사용하지 않습니다. 성공 자료는 1시간, 실패 상태는 5분 캐시합니다.

`GET /api/knowledge/iros-chat`에서 수집 상태(ready/unavailable/no_public_qa), 수집 건수, 확인 시각, 확인한 공개 자산과 오류를 확인합니다. 공개 자료에 Q/A 본문이 없거나 연결 실패 시 기존 공식 자료로 답변하며 안내봇을 참고했다고 표시하지 않습니다. 미확인 API 주소를 추정해 호출하지 않습니다. 동적 API의 요청은 2026.10.14. 공개된 main.818b0933.js에서 확인한 필드(user_id, in_type, in_str, session_id, channel_id, parameters)를 사용합니다. data.result.fulfillment의 response_status가 match인 실제 답변만 근거로 선정하고, suggest/multi_intent 메뉴는 답변으로 사용하지 않습니다. 최대 6개 질의의 표본 수집으로 안내봇 전체 지식의 복제는 아닙니다. API 형식이나 정책이 변경되면 연계 보완이 필요합니다.

상속·매매·근저당권·법인등기·전자신청 등 미리 정한 일반 주제에 해당하면 해당 주제를 공식 안내봇에 추가 조회하고 관련 선택 질문을 최대 3회 탐색합니다. 이름·주소·금액·사용자 문장을 전송하지 않고 코드에 정한 일반 주제만 전송합니다. 이는 안내봇 전체 질문·답변을 수집한 데이터베이스가 아니라, 공식 답변을 필요 시 조회하는 연계입니다.
